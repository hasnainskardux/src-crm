# SRC Real Estate CRM Dashboard — Skardu, Gilgit-Baltistan

A premier SaaS Real Estate CRM Dashboard designed and built for **SRC Real Estate Agency** located in **Skardu, Gilgit-Baltistan, Pakistan**.

Built with modern React, TypeScript, and Tailwind CSS, featuring high-fidelity pixel replication of the reference real estate management architecture with full frontend interactivity, realistic Pakistani market demo records, and zero backend friction.

---

## 🌟 Key Features

1. **Executive Dashboard**:
   - Four real-time statistics cards: Total Properties (59), Properties for Sale (23), Properties for Rent (36), New Leads (320).
   - Sales growth trend line chart in PKR currency with interactive data point inspection.
   - Sales reports table showing verified customer transactions.
   - New properties thumbnail widget & live customer direct chat drawer.

2. **Properties Management**:
   - 4-column responsive grid view matching Landify/SRC visual reference.
   - Professional table list view with status badges (Available, Pending, Approved, Rented, Sold) and publication indicators.
   - Live search, filtering by property type and status, sorting, and pagination.
   - Add Property modal, Edit Property modal, and full Property Dossier profile with photo carousel.
   - One-click [Send Mail] brochure dispatch modal.

3. **Leads Management**:
   - Full 8-stage sales pipeline: New, Contacted, Interested, Qualified, Meeting Scheduled, Negotiation, Converted, Lost.
   - Drag-and-drop / stage move Kanban board and high-density tabular view.

4. **Development Projects**:
   - Flagship projects including *SRC Mountain Residency*, *Skardu Valley Heights*, *Alpine Luxury Homes*, and *SRC Commercial Plaza*.
   - Unit inventory counters and sales progress bars.

5. **Legal Agreements & Deeds**:
   - Sale Agreements, Tenancy Deeds, Booking Contracts, and Property Management contracts.
   - Stamp-paper style legal document preview for Skardu district courts.

6. **Interactive Calendar & Appointments**:
   - Month, Week, Day, and Agenda viewing modes.
   - Color-coded property visits, customer meetings, check-ins, and follow-up calls.
   - Prepared architecture for Google Calendar API integration.

7. **Contacts, Brokers & Campaigns**:
   - Centralized buyer, property owner, and corporate tenant directory.
   - External broker commission tracking.
   - Marketing campaigns analytics across Meta ads and WhatsApp broadcasts.

8. **Settings & Future Cloud Connectors**:
   - Business Profile: SRC in Skardu, Gilgit-Baltistan, Pakistan (PKR currency, Asia/Karachi timezone).
   - Clean "Coming Soon" integration cards for Supabase, Google Calendar, Google Maps, and WhatsApp Business API.
   - One-click **Demo Data Reset** to restore pristine presentation state anytime.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/src-real-estate-crm.git

# Navigate to project folder
cd src-real-estate-crm

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## ☁️ Deployment on Vercel

1. Push your repository to **GitHub**.
2. Go to [Vercel Dashboard](https://vercel.com/new) and click **Import Project**.
3. Select your repository.
4. Framework Preset: **Vite**
5. Root Directory: `./`
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Click **Deploy**.
